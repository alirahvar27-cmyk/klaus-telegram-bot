# نقشه پروژه کلاوس — مرجع ثابت فارسی

این مخزن دو ربات جداگانه دارد. شباهت نام «کلاوس» به معنی یکی بودن وظایف یا اجازه تغییر مشترک نیست.

## ۱) ناشر خودکار
- فایل برنامه: `main.py`
- گردش‌کار: `.github/workflows/post.yml`
- وظیفه: خودش محتوا تولید می‌کند و هر دو ساعت یک‌بار برای ۱۴ کانال منتشر می‌کند.
- اصل حفاظت: وقتی درخواست مربوط به «دستیار» است، `main.py` و `post.yml` را تغییر نده.

## ۲) دستیار انتشار
- فایل برنامه: `telegram_approval_bot.py`
- گردش‌کار: `.github/workflows/telegram-approval-bot.yml`
- وضعیت پایدار پیش‌نویس‌ها: `telegram_approval_state.json`
- وظیفه: کاربر متن/عکس/فیلم می‌فرستد؛ ربات پیش‌نمایش می‌دهد و فقط پس از تأیید مدیر در کانال انتخاب‌شده منتشر می‌کند.
- Secretهای اصلی: `TELEGRAM_BOT_TOKEN` و `ADMIN_USER_ID`. مقدار `ADMIN_USER_ID` شناسه عددی مدیر است و فقط در گردش‌کار دستیار به‌عنوان secret خوانده می‌شود.
- گردش‌کار دستیار هر ۵ دقیقه اجرا می‌شود و در هر نوبت حداکثر ۲۴۰ ثانیه پیام‌ها را پردازش می‌کند. وضعیت پیش‌نویس‌ها بین اجراها در فایل JSON ذخیره می‌شود.
- اصل حفاظت: قابلیت‌های مربوط به پیش‌نویس، تأیید، انتخاب کانال، زمان‌بندی و سانسور را فقط در فایل دستیار و گردش‌کار خودش بررسی کن. به ناشر دست نزن.

## درخواست‌های فعلی دستیار
1. زمان‌بندی اختیاری: کاربر بتواند تاریخ و ساعت تهران را برای یک پیش‌نویس مشخص کند. پیش‌نویس‌های عادی بدون زمان‌بندی همان روند قبلی را داشته باشند. زمان‌بندی تنها پس از تأیید مدیر نهایی شود.
2. سانسور پیش‌نویس: موارد موجود در فهرست مسدودشده‌ای که کاربر در گفت‌وگو فرستاده، قبل از نمایش پیش‌نویس حذف شوند؛ پاک‌سازی نباید متن عادی را بی‌دلیل حذف کند.
3. حفظ دریافت متن/عکس/فیلم، پیش‌نمایش، تأیید، تغییر کانال، آلبوم رسانه و انتشار موجود.

## چک‌لیست اجباری قبل از هر تغییر
- اول مشخص کن درخواست برای «ناشر» است یا «دستیار».
- فقط فایل‌ها و workflow متعلق به همان ربات را تغییر بده.
- قبل از ویرایش، نسخه فعلی و commit را بخوان.
- تغییرات را کوچک و افزایشی نگه دار؛ کد سالم و مسیرهای دیگر را بی‌دلیل بازنویسی نکن.
- اجرای `python -m py_compile telegram_approval_bot.py` و گردش‌کار Validate را بررسی کن.
- بعد از commit، نتیجه Actions و کد واقعی را بررسی کن؛ تا سبز نشود یا رفتار واقعی تأیید نشده، ادعای «کاملاً تست شده» نکن.
- هر دو ربات از توکن تلگرام ممکن است مشترک استفاده کنند، اما این به معنی یکی بودن پردازش‌ها نیست. برای دستیار فقط `ADMIN_USER_ID` و workflow مربوط به خودش را ملاک بگیر.
